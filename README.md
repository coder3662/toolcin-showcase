# Toolcin — 432 browser tools that never upload your files

**Live site:** https://toolcin.pages.dev

Toolcin is a set of 432 small utilities that run entirely in the browser: text tools, developer utilities, image editors, PDF and file converters, calculators, SEO helpers and generators. Nothing is uploaded, there is no account, and there is no database — every file you open stays on your own device.

Alongside the toolbox the site keeps two live sections:

- **Trending dramas, movies and series** — ranked by real public interest (Wikimedia pageviews), one page per title, with cast and official links.
- **Live scores** — cricket, football and basketball cards that refresh on their own.

## What it is built with

Plain HTML, CSS and JavaScript, generated by a small Node build script and served as static files from Cloudflare's edge. No framework, no tracker, no ad, no third-party request on a normal page.

## Why it exists

Most "free online tool" sites upload your file to a server you cannot see. A tool that does its work in the tab needs no upload endpoint, so there is nothing to leak, log or sell. That is the whole idea.

## Notes

- The site is free and carries no advertising.
- Data used by the trending and score pages is openly licensed or comes from the provider's own public feed; every card links back to the source.
- Application source is not published in this repository.

**Try it:** https://toolcin.pages.dev
